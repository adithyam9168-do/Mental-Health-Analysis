# Mental Health Analysis – End-to-End Data Analytics Project

## 📌 Project Overview

This project focuses on analyzing mental health awareness and related factors using survey data.

The project follows an end-to-end data analytics workflow, including data collection, data cleaning, Excel analysis, SQL analysis, Python Exploratory Data Analysis (EDA), Power BI dashboard development, and final project presentation.

## 🎯 Project Objectives

- Analyze mental health awareness across different demographic groups
- Identify patterns and trends in mental health conditions
- Analyze the relationship between mental health awareness and reported conditions
- Perform data cleaning and transformation
- Generate meaningful insights using data analysis and visualization
- Build an interactive Power BI dashboard
